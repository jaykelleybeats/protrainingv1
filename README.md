# DropZone FN

A Fortnite improvement hub: a single static page (`index.html`) plus a few Netlify Functions for player lookups and authorized stats.

- **Frontend:** plain HTML/CSS/JS in `index.html` (no build step)
- **Backend:** Netlify Functions in `netlify/functions/`
- **Stats setup:** see `README-STATS-CONNECTION.md` for the environment variables the stats function needs

## Run locally

```bash
netlify dev
```
